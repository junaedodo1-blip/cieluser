# HARD RULE: AI Visual Prompt Cookbook Round-Robin Directive

## Mandatory Production Rule

1. **Brand Logo Consistency**: The project\\ciel wordmark/logo remains the sole fixed brand anchor across all carousels.
2. **100% Cookbook Visual Authority**: All visual aesthetics—color palettes, background environments, typography hierarchy, lighting setups, textures, camera perspectives, and graphic decal elements—are 100% strictly governed by the Day's active **AI Visual Prompt Cookbook** specification (data/ai_visual_prompt_cookbook/*.json).
3. **Round-Robin Rotation**: The visual style rotates sequentially through all 126 Cookbook specifications, tracking state in carousel_automation_state.json. No style repeats until a full 126-style cycle finishes.
4. **Dynamic Copy & Topic Adaptation**: Each day's active topic title, research thesis, subhead, body cards, and CTA trigger words are injected directly into the active Cookbook style template.
